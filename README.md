# ДОЗОР

Ночной автономный агент Лёни. Каждое утро в 6:30 в облаке просыпается Claude-агент, обходит источники, проверяет сайты, смотрит на дедлайны — и присылает в Telegram короткую выжимку с выводами.

Здесь лежит только **сбор фактов**. Смысл, отбор и формулировки — работа агента, который эти факты читает.

## Части

| Файл | Что делает |
|---|---|
| `dozor.js` | Собирает сырьё: свежее из источников, коды ответа сайтов, счётчик дедлайнов → `report.json` |
| `notify.js` | Отправляет готовый текст в Telegram (разбивает на части, безопасно экранирует) |
| `sources.json` | Единственный файл для настройки: источники, сайты, интересы, дедлайны |

## Запуск вручную

```
node dozor.js              # человекочитаемый вывод + report.json
node dozor.js --json       # только JSON (для агента)
node dozor.js --days 7     # окно в днях

TG_TOKEN=... TG_CHAT=... node notify.js письмо.md
```

## Настройка источников — `sources.json`

| Тип | Поля | Где взять |
|---|---|---|
| `youtube` | `handle` (`Fireship`) **или** `channelId` | Хэндл из адреса канала — ID агент найдёт сам |
| `github` | `repo` (`owner/name`), `kind` (`releases`/`commits`) | Из адреса репозитория |
| `telegram` | `channel` (без `@`) | Имя публичного канала |
| `rss` | `url` | Ссылка на RSS/Atom |

Дополнительно у любого источника: `topic` — тема для группировки, `days` — своё окно в днях (для редких тем).

Ни один источник не требует ключа или регистрации.

## Проверка сайтов

`sites` — список страниц Лёни. HTTP 200 сам по себе ничего не значит, поэтому ДОЗОР дополнительно смотрит, что страница не пустая, и — если задано поле `expect` — что на ней есть опорная строка.

## Секреты

В репозитории их нет. Токен бота и chat_id живут в настройках облачного расписания и передаются агенту через переменные окружения.
