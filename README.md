# ДОЗОР

Фоновый агент Лёни. Живёт в Планировщике заданий Windows, будит Claude Code по расписанию и общается с Лёней через Telegram-бота «Сводка» (@news_leonidbot).

Скрипты только собирают факты. Смысл, отбор и формулировки — работа Claude, который эти факты читает.

## Что делает

| Когда | Задача | Что происходит |
|---|---|---|
| Каждый день 6:30 | `DOZOR` | Утренняя сводка: 22 источника, состояние сайтов, дедлайн, пять слов китайского. Стоящее откладывает в базу знаний |
| Каждый час | `DOZOR-Watch` | Сторож сайтов. Пишет **только** когда что-то упало или снова поднялось |
| Каждые 10 минут | `DOZOR-Chat` | Проверяет, не написал ли Лёня боту. Если написал — будит Claude, тот отвечает |
| Воскресенье 20:00 | `DOZOR-Week` | Итоги недели: что сделано, где стоим, что горит до 1 сентября |
| Среда 20:00 | `DOZOR-SHOS` | Ищет свежую фактуру для научной статьи, складывает в `shos-article/nahodki.md` |

Claude просыпается только когда есть работа: проверка сообщений и сторож сайтов — обычный Node, дешёвые и быстрые.

## Части

| Файл | Что делает |
|---|---|
| `dozor.js` | Собирает сырьё: источники, коды ответа сайтов, счётчик дедлайнов → `report.json` |
| `watch.js` | Сторож сайтов: сравнивает с прошлым разом, шлёт только изменения |
| `chat.js` | Забирает новые сообщения из Telegram в `vopros.txt`. Код выхода 0 — есть вопрос, 2 — тихо |
| `kitajskij.js` | Пять слов из базы СЮЭ по кругу, позиция запоминается в `state.json` |
| `notify.js` | Отправка в Telegram: режет длинный текст, безопасно экранирует |
| `sources.json` | Настройка: источники, сайты, интересы, дедлайны |
| `slova.json` | 160 слов HSK 3–4, извлечены из приложения СЮЭ |
| `zadacha*.md` | Инструкции агенту: утро, чат, неделя, статья |
| `run-task.ps1` | Запуск задачи: `-Task dozor` / `nedelya` / `shos` |
| `run-chat.ps1`, `run-watch.ps1` | Запуск чата и сторожа |
| `secrets.ps1` | Токен бота и chat_id. **В репозиторий не попадает** |

## Управление

```powershell
Get-ScheduledTask -TaskName DOZOR*                    # все задачи и их состояние
Start-ScheduledTask -TaskName DOZOR                   # прислать сводку прямо сейчас
Disable-ScheduledTask -TaskName DOZOR-Chat            # выключить ответы бота
```

Вручную: `powershell -File run-task.ps1 -Task nedelya`. Ход работы — в `dozor.log`, `chat.log`, `watch.log`.

## Настройка источников — `sources.json`

| Тип | Поля | Где взять |
|---|---|---|
| `youtube` | `handle` (`Fireship`) **или** `channelId` | Хэндл из адреса канала — ID агент найдёт сам |
| `github` | `repo` (`owner/name`), `kind` (`releases`/`commits`) | Из адреса репозитория |
| `telegram` | `channel` (без `@`) | Имя публичного канала |
| `rss` | `url` | Ссылка на RSS/Atom |

Дополнительно: `topic` — тема для группировки, `days` — своё окно в днях для редких тем вроде грантов.

Ни один источник не требует ключа или регистрации. Можно и просто написать боту: «добавь источник такой-то» — агент сам поправит файл.

## Проверка сайтов

HTTP 200 сам по себе ничего не значит, поэтому проверяется ещё и что страница не пустая, а если задано `expect` — что на ней есть опорная строка. При сетевой ошибке делается вторая попытка: разовый сбой не должен поднимать ложную тревогу.

## Почему не в облаке

Сначала это делал облачный агент по расписанию. Расписание создавалось, но сессии не запускались: без подключённого к аккаунту GitHub облачной среде нечего разворачивать, и запуск гас молча — не доходил даже пинг первой строкой. Vercel как запасной путь отпал: платформа не отдаёт значения секретов обратно.

Локальный запуск оказался и проще, и лучше: письма пишет Claude, а не модель попроще, секреты никуда не уезжают, а «запустить при первой возможности» закрывает случай выключенного компьютера.
