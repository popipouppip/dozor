# ДОЗОР

Утренний агент Лёни. Каждый день в 6:30 Планировщик Windows запускает Claude Code в фоновом режиме: тот собирает свежее из 22 источников, проверяет сайты, смотрит на дедлайны, отбирает важное — и присылает короткую сводку в Telegram.

Скрипты только собирают факты. Смысл, отбор и формулировки — работа Claude, который эти факты читает.

## Части

| Файл | Что делает |
|---|---|
| `dozor.js` | Собирает сырьё: свежее из источников, коды ответа сайтов, счётчик дедлайнов → `report.json` |
| `notify.js` | Отправляет готовый текст в Telegram (режет на части, безопасно экранирует) |
| `sources.json` | Единственный файл для настройки: источники, сайты, интересы, дедлайны |
| `zadacha.md` | Инструкция агенту: кто такой Лёня, что отбирать, как писать письмо |
| `run-dozor.ps1` | Запуск для Планировщика: поднимает Claude Code с этой инструкцией |
| `secrets.ps1` | Токен бота и chat_id. **В репозиторий не попадает** |

## Как это запускается

Задача `DOZOR` в Планировщике заданий Windows, ежедневно в 6:30. Включено «запустить при первой возможности» — если компьютер был выключен, сводка придёт вскоре после включения.

```powershell
Get-ScheduledTask -TaskName DOZOR                  # состояние
(Get-ScheduledTaskInfo -TaskName DOZOR).NextRunTime # когда следующий запуск
Start-ScheduledTask -TaskName DOZOR                 # запустить прямо сейчас
Disable-ScheduledTask -TaskName DOZOR               # временно выключить
```

Вручную, без планировщика: `powershell -File run-dozor.ps1`. Ход работы пишется в `dozor.log`.

## Запуск отдельных частей

```
node dozor.js              # человекочитаемый вывод + report.json
node dozor.js --json       # только JSON (это читает агент)
node dozor.js --days 7     # окно в днях

TG_TOKEN=... TG_CHAT=... node notify.js pismo.md
```

## Настройка источников — `sources.json`

| Тип | Поля | Где взять |
|---|---|---|
| `youtube` | `handle` (`Fireship`) **или** `channelId` | Хэндл из адреса канала — ID агент найдёт сам |
| `github` | `repo` (`owner/name`), `kind` (`releases`/`commits`) | Из адреса репозитория |
| `telegram` | `channel` (без `@`) | Имя публичного канала |
| `rss` | `url` | Ссылка на RSS/Atom |

Дополнительно у любого источника: `topic` — тема для группировки, `days` — своё окно в днях (для редких тем вроде грантов).

Ни один источник не требует ключа или регистрации.

## Проверка сайтов

`sites` — страницы Лёни. HTTP 200 сам по себе ничего не значит, поэтому ДОЗОР ещё смотрит, что страница не пустая, и — если задано `expect` — что на ней есть опорная строка. При сетевой ошибке делается вторая попытка, чтобы разовый сбой не поднимал ложную тревогу.

## Почему не в облаке

Сначала это делалось облачным агентом по расписанию (routine). Расписание создавалось, но сессии не запускались: без подключённого к аккаунту GitHub облачной среде нечего разворачивать, и запуск гас молча — не доходил даже пинг первой строкой. Vercel как запасной путь отпал: платформа не отдаёт значения секретов обратно, и ключ для стороннего ИИ достать было неоткуда.

Локальный запуск оказался и проще, и лучше: письмо пишет Claude, а не модель попроще, секреты никуда не уезжают, а «запустить при первой возможности» закрывает случай выключенного компьютера.
